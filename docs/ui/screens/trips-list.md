# Mes Voyages — décision visuelle

Il n’existe pas de template 1:1 pour la liste des Voyages. L’écran compose le langage du tableau de bord (`templates/ui/04-trip-dashboard.html`) — cartes, membres, progression et puces — avec la hiérarchie du récapitulatif (`templates/ui/09-trip-recap.html`) pour préparer un futur état post-voyage.

La liste affiche uniquement les données du Module Trips : nom, dates locales, devise, membres, Étapes et état réel du TripPack hors ligne. Aucune image Lisbonne, statistique inventée ou donnée de récapitulatif n’est affichée comme réelle. Le récapitulatif reste explicitement « À venir ».
